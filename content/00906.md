kubectl で全Podのイメージを一覧するメモです

```bash
kubectl get pods -A -o jsonpath="{range .items[*]}{range .spec.initContainers[*]}{.image}{'\n'}{end}{range .spec.containers[*]}{.image}{'\n'}{end}{end}" | sort -u
```
