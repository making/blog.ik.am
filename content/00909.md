Mac Mini (M4 Pro, 64GB)にremoteからsshでログインして、[mlx-serve](https://github.com/ddalcu/mlx-serve)をインストール、サービス化するメモ

### mlx-serveのインストール

```bash
brew trust ddalcu/mlx-serve
brew trust --cask ddalcu/mlx-serve/mlx-core
brew tap ddalcu/mlx-serve https://github.com/ddalcu/mlx-serve
brew install mlx-serve
```

```bash
mlx-serve pull ddalcu/Qwen3.8-27B-MLX-Serve-8bit
```

### mlx-serveのサービス化

#### plistファイルの作成

ユーザー名は`maki`の想定。

```xml
sudo tee /Library/LaunchDaemons/am.ik.mlx-serve.plist > /dev/null << 'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>am.ik.mlx-serve</string>

    <key>ProgramArguments</key>
    <array>
        <string>/opt/homebrew/bin/mlx-serve</string>
        <string>serve</string>
        <string>--metrics</string>
    </array>

    <key>WorkingDirectory</key>
    <string>/Users/maki</string>

    <key>UserName</key>
    <string>maki</string>

    <key>EnvironmentVariables</key>
    <dict>
        <key>PATH</key>
        <string>/usr/local/bin:/opt/homebrew/bin:/usr/bin:/bin:/usr/sbin:/sbin:/Users/maki/.local/bin</string>
        <key>HOME</key>
        <string>/Users/maki</string>
    </dict>

    <key>RunAtLoad</key>
    <true/>

    <key>KeepAlive</key>
    <true/>

    <key>StandardOutPath</key>
    <string>/Users/maki/Library/Logs/mlx-serve.out.log</string>

    <key>StandardErrorPath</key>
    <string>/Users/maki/Library/Logs/mlx-serve.err.log</string>
</dict>
</plist>
EOF
```

LaunchDaemon は root所有・644 でないと読み込まれない。

```bash
sudo chown root:wheel /Library/LaunchDaemons/am.ik.mlx-serve.plist
sudo chmod 644 /Library/LaunchDaemons/am.ik.mlx-serve.plist
```

#### サービス読み込み

```bash
mkdir -p /Users/maki/Library/Logs
sudo launchctl bootstrap system /Library/LaunchDaemons/am.ik.mlx-serve.plist
```

### 運用系コマンドメモ


| 操作 | コマンド |
|---|---|
| 再起動 | `sudo launchctl kickstart -k system/am.ik.mlx-serve` |
| 停止・アンロード | `sudo launchctl bootout system/am.ik.mlx-serve` |
| 再度読み込み | `sudo launchctl bootstrap system /Library/LaunchDaemons/am.ik.mlx-serve.plist` |
| 状態確認 | `sudo launchctl list \| grep am.ik.mlx-serve` |
| plist編集後の反映 | 一度 bootout → bootstrap し直す |

### スリープ防止

```bash
sudo pmset -a sleep 0 disksleep 0
```
